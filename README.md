# FAQ Chatbot Using NLP and Python

## Project Overview
This project is a Frequently Asked Questions (FAQ) chatbot developed using Python and Natural Language Processing (NLP). It matches user questions with predefined FAQs and returns the most relevant answer.

## Features
- Text preprocessing and cleaning
- TF-IDF vectorization
- Cosine similarity for question matching
- Automated FAQ responses
- Interactive graphical user interface using Tkinter

## Technologies Used
- Python
- Scikit-learn
- Natural Language Processing
- TF-IDF
- Cosine Similarity
- Tkinter

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python app.py
```

## Learning Outcomes
This project demonstrates practical knowledge of NLP, text similarity, Python programming, and chatbot development.
